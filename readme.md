SET UP AND NAMES 
We used proper CamelCase names (like playgame) without underscores to prevent errors.

GAME FUNCTIONS
displayWelcome: It shows the welcome message at the start of the game.
getSecretNumber: Pick a random number from 1-10.
playGame: Handles the core game play where player has 3 tries to guess the number.
main: Connets and run all the functions together in order.

HOW THE GAME WORKS
the player gets 3 tries to make a guess
the program tells the player if the guess it "Too High","Too low", or correct.
If the player runs out of time without guessing it, a "Game Over" message appears.
